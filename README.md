# Family HQ

A kid-friendly planner for school work and chores. It's one page with no build step.

Open it here: https://tier3hold-cmd.github.io/family-hq/

- Built for a landscape screen: kid tabs and a Calendar tab across the top, a sticky School / Chores sidebar on the left.
- One tab per kid: school items for this week and next, basic chores, money jobs, a daily verse, and a daily workout or gymnastics move with a short how-to video.
- Calendar tab: family events, plus an embedded Google Calendar when one is linked.
- Parents tab (code 1234): completion status, grading, chore and pay editing, adding assignments, and a timestamped history.
- Checkmarks and history are saved in the browser on each device.
